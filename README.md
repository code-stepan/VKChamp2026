# VK Case Champ 2026 — социальная коммерция в бизнес-сообществах

Аналитический проект по кейсу «Развитие элементов социальной коммерции для бизнес-сообществ во ВКонтакте».
Данные: `uploads/data.xlsx` (7 листов, сентябрь 2026) + условия кейса в PDF.

## Как запустить

```bash
python -m pip install -r requirements.txt
python run_all.py            # все ноутбуки по порядку
python run_all.py 02 05      # только выбранные
```

`run_all.py` конвертирует `notebooks/*.py` (jupytext percent) в `.ipynb`, исполняет их и сохраняет
выводы в ноутбуки, графики — в `outputs/figures`, таблицы — в `outputs/tables`,
ключевые числа — в `outputs/key_numbers.json`.

> Источник правды — `.py`-файлы ноутбуков. `.ipynb` пересобираются из них.

## Структура

```
vkcase/            # переиспользуемый код
  config.py        # пути, листы, палитра, внешние константы
  data.py          # загрузка и подготовка 7 листов, флаги аномалий
  analysis.py      # воронки, сегментация, логит, PSM, ML, декомпозиции, robustness
  viz.py           # графики в едином стиле
notebooks/         # исследование по шагам
  00_data_audit            # аудит данных, аномалии, сверка листов, границы выводов
  01_business_segments     # воронка инструментов, сегменты, активация, реклама
  02_content_and_drivers   # контент, логит, PSM, ML: что связано с продажей
  03_market_vs_partner     # Маркет vs Партнёр: где теряется покупатель, роль Маркета
  04_role_sizing_strategy  # сценарии, монетизация, путь бизнеса, KPI, роадмап
  05_robustness_and_summary# проверка устойчивости выводов и сводка чисел
reports/           # handover-отчёт для команды
  research_findings.md     # полный текст: 16 рисунков, 56 таблиц
  research_findings.html   # self-contained HTML (картинки внутри, 1,8 МБ)
  research_findings.docx   # редактируемый DOCX (A4)
  make_figures.py          # 7 графиков специально для отчёта
  build_report.py          # сборка HTML/DOCX из Markdown
  tex/                     # PDF-версия: LaTeX-исходники + готовый файл
    VK_Case_2026_handover.pdf  # 36 страниц A4, готов к отправке
    build_tex.py               # Markdown → main.tex
    README.md                  # как пересобрать (XeLaTeX, 2 прохода)
outputs/           # figures, tables, key_numbers.json
work/              # черновые выгрузки и explore-скрипты (не часть пайплайна)
```

## Отчёт для команды

```bash
python reports/make_figures.py    # графики отчёта
python reports/build_report.py    # HTML + DOCX из research_findings.md
```

Открывать `reports/research_findings.html` (один файл, ничего не нужно рядом)
или `reports/research_findings.docx` для правок. Внутри — контекст кейса и требования PDF,
метод и границы выводов, ответы на 5 задач, концепция «Маркет как слой», целевой путь,
сценарии и монетизация, риски, раскладка на 8 слайдов, план для коллег и AI disclosure.

PDF для отправки — `reports/tex/VK_Case_2026_handover.pdf` (36 страниц, шрифты внутри).
Пересборка после правок Markdown:

```bash
python reports/tex/build_tex.py
cd reports/tex && xelatex main.tex && xelatex main.tex
```

Подробности — `reports/tex/README.md`.

## Главные результаты

| Блок | Результат |
|---|---|
| Выборка | 9 754 сообщества, медиана 490 подписчиков; 0,64% платформенного GMV |
| Активация | каталог у 40,6%; чекаут у 58,8%; полный стек — 0,96%; **94,8% подключивших чекаут не продают** |
| Контент | товарный пост собирает **×1,9** просмотров, но **×0,54** ER; публикуют 3,1%; CTR в карточку 0,29% |
| Драйверы | ассортимент (OR 1,52) и охват (OR 1,45) сильнее инструментов; реклама не связана с продажей (OR 1,02, p=0,31) |
| Доставка | наивно ×3,2 → PSM **+2,8…3,5 п.п.** первой продажи; во всех 8 спецификациях ДИ включает 0; объём заказов не растёт |
| Воронка VK | CTR показа→открытие 4,05% (лучше Партнёра), но открытие→кнопка **3,08% vs 42,16%**; 106% разрыва — этот шаг |
| Разрыв VK vs Партнёр | состав трафика **−14%**, механика внутри категорий **+114%** — проблема в карточке, а не в аудитории |
| Масштаб Маркета | DAU 127 тыс. = 0,14% DAU VK; 28,6 млн товарных запросов/мес |
| Тренды (с поправкой на день недели) | заказы Маркета −0,5%/день (p=0,008), Партнёра +0,7%/день (p=0,002) |
| Сценарии | заказы 0,77 / 1,70 / 4,35 млн/мес; GMV 2,79 / 5,62 / 12,63 млрд ₽/мес; выручка базового — ≈143 млн ₽/мес |

## Что важно не утверждать

* причинный эффект инструментов — данные наблюдательные, есть self-selection;
* реальную выручку и ROI бизнеса — 98,8% заказов не оплачены внутри VK;
* ROAS рекламы — GMV через чекаут даёт только нижнюю оценку;
* сезонность и долгосрочный рост — в данных один месяц;
* точные доли категорий — сумма заказов по категориям расходится с итогами на 5–7%.

Подробный список — `outputs/tables/05_claims_not_supported.csv`.
